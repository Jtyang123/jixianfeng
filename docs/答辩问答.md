# 答辩高频问题与回答要点

## 1. 这个项目是不是四个提示词串起来？

不是。四个 Agent 有独立角色、工具白名单、输入输出 Schema、记忆范围和禁止事项。工作流包含并行入口、条件分支、核验门控和两轮回环。更关键的是，核验 Agent 使用隔离上下文和确定性规则，只返回问题代码、证据和修正要求；生成 Agent 不能给自己打分。匹配 Agent 必须根据核验反馈改变路线和资源分配，最终结果会经过第二次核验和人工审批。

## 2. 为什么不能直接用一个强模型生成方案？

单模型可以生成文本，但无法保证库存、载重、ETA、道路封闭和需求覆盖计算正确，也缺少独立否决机制。我们把事实计算和规则核验从模型中拆出，让 LLM 负责理解和解释，让工具负责数字，让核验角色负责否决，让人类负责最终责任。这样可以降低幻觉传播，并让每个结论可追溯。

## 3. LLM 在系统中的具体作用是什么？

需求 Agent 用 LLM 理解灾情描述和用户意图；匹配 Agent 用 LLM 解释多目标权衡与重规划理由；核验 Agent 用 LLM 归纳问题根因，但不能改变硬规则结论；交付 Agent 用 LLM 组织执行摘要和风险提示。未配置 LLM 时，系统回退到本地确定性模式，保证断网演示可靠性。提交评审前应配置 AgentArts/LLM 环境变量并录制真实调用证据。

## 4. 系统如何体现动态调度？

调度器读取事件等级、受影响人口、物资种类和封闭路线数量，计算任务复杂度，再按角色能力、依赖关系和安全等级生成优先级和批次。需求研判与 RAG 检索并行，资源匹配顺序执行，独立核验使用门控优先级，交付必须等待人工审批。调度决策、复杂度和回环策略都会进入运行事件流。

## 5. 自我循环如何收敛？

第一轮方案可能使用主通道，但核验读取事件封闭清单后发现硬阻断，返回 rework。反馈只包含问题代码、证据和修正要求，匹配 Agent 在第二轮排除封闭路线、改走备用通道并重新计算车辆和成本。第二轮核验通过后收敛。最多两轮，仍未通过则升级人工研判，避免无限循环。基准中评分由 0 提升至 100，需求覆盖率 100%。

## 6. 结果如何验证，不是自己说自己好？

第一，安全约束由确定性规则计算，不依赖模型自评。第二，核验 Agent 与生成 Agent 上下文隔离，且没有编辑权限。第三，系统保存库存快照、候选方案、核验报告和人工审批记录。第四，评估接口用同一快照重复计算，并比较阻断清单和通过方案 ID。第五，后端有自动化测试覆盖闭环和 API。

## 7. 数据从哪里来？

比赛原型使用明确标识的模拟演练数据。用户可以上传物资库、库存、仓库、车辆和路线；系统形成版本化库存快照。生产落地需接入授权的应急指挥、仓储、交通和物流系统。平台不宣称自动发现灾害，也不访问真实储备库。

## 8. 为什么不用实时灾害监测？

本项目定位为“事件确认后的调度推演与预案生成”。灾害发现属于监测和应急指挥体系，需要气象、水利、地震、消防、热线、遥感等多源系统交叉验证。原型不越界承诺。真实落地时可接入官方事件推送，但 Agent 只在事件确认后生成调度草案，最终由人工批准。

## 9. 与 Dify、LangChain 等框架的区别是什么？

平台可以使用通用框架，但核心创新在自定义的独立核验与结构化回环：生成和验证职责分离；核验只读；硬规则不可被模型覆盖；反馈只传问题代码和证据；方案版本与库存快照绑定；结果可复现。即使换成其他 Agent 运行时，这些机制仍然有效。

## 10. 如何保证安全与隐私？

密钥只在服务端，当前原型不接入真实个人信息。生产环境需要 HTTPS、身份认证、角色权限、数据库加密、审计日志、敏感字段脱敏、数据分级、备份恢复和按项目隔离。真实储备库位置和车辆数据需要严格授权，不能公开。

## 11. 量化效果有哪些？

固定压力测试场景中，第一轮发现 7 类硬阻断，3/3 不安全方案被拦截；第二轮 3 套方案通过，需求覆盖 100%，评分由 0 提升至 100；重复计算结果一致；纯规划计算约 1 毫秒。现场完整流程约 20–40 秒，主要耗时来自可视化事件节奏和外部模型调用。

## 12. 项目的商业化或落地路径是什么？

第一阶段面向园区、学校、医院、社区和演练服务机构，提供私有化预案推演；第二阶段与一个场景合作方做授权数据演练；第三阶段接入 WMS/ERP、地图、车队和指挥系统；第四阶段沉淀行业 Agent、规则和报告模板。商业模式可以是私有化授权、演练服务、行业模板订阅和集成实施。

## 13. 目前最大的局限是什么？

一是没有真实灾害监测和真实调度接口；二是模拟数据不能证明行业准确率；三是规则库需要行业专家审核；四是当前路由问题做了简化，生产环境需要处理多商品、多车型、多站点和动态路况；五是 LLM 未配置时只能使用确定性回退。

## 14. 如果现场演示断网怎么办？

核心规划、库存校验、道路校验、方案生成和人工审批均可在本地运行；前端静态资源由 FastAPI 托管；AgentArts/LLM 不可用时自动回退。这样评审现场不会因网络或模型额度导致核心流程失败。真实模型调用可作为附加演示，不作为唯一依赖。

## 15. 团队如何分工？

建议 3–4 人：一人负责 Agent 编排、调度和后端规则；一人负责 Vue 工作台和可视化；一人负责数据导入、测试、评估和文档；一名队长负责场景定义、答辩、视频和整体集成。所有成员都应理解数据边界和 AI 贡献边界。
