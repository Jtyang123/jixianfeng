# 急先锋 4 分钟演示视频脚本

目标时长：3-5 分钟，推荐成片 4:00。录制方式：屏幕录制，不自动生成视频。  
主场景：`rainstorm-ii`。主运行时：`llm-planner`。  
视觉重点：Planner 推理轨迹、调度明细、阶段耗时、核验退回后重算通过、A2A 与记忆。

## 录制前检查单

1. 运行 `cd backend && ../.venv/Scripts/python.exe -m benchmark.demo_preflight`，确认 `blockers` 为空数组、`recent_runs.needs_human_ratio=0.0`、`agentarts.online_rate=1.0`、`recommended_demo_mode=llm-planner`；同一次输出里 `preferred_scenarios` 会把 `heatwave-iii`、`rainstorm-ii` 排在前面。
2. 正式录制前 dry-run 一次完整 run，确认运行详情显示 `final_verification.verdict=pass` 且状态为 `awaiting_approval`。
3. 关闭所有显示 `.env`、API Key、Authorization、终端历史记录和本地数据库路径的窗口；录制画面中禁止出现密钥。
4. 浏览器缩放建议 80%-90%，关闭无关标签页、聊天软件通知和系统弹窗。
5. AgentArts 检测区域如已有缓存结果可直接展示；不要为了录制重复触发真实推理。
6. 不要现场点击以下按钮：
   - 知识库自由文本检索：hash 模式下临时改写成近义句可能返回空。
   - AgentArts“检测/重新检测”：会真实发起 4 次推理，延迟约 2.6-15.7 秒且消耗配额。
   - 任何一次新的 benchmark：分钟级任务，不进入演示视频。

## 录制兜底

- 如果 dry-run 落到 `needs_human`：切到 `demo_preflight.scenario_risk` 中 `human_ratio` 最低的备份场景重跑一次，讲解词改为“系统识别到道路全封闭，主动转为人工研判，不做假通过”。这是能力展示，不是失败。
- 如果 AgentArts 延迟波动：不要重复点检测，直接展示缓存的 4/4 在线结果。
- 如果 Planner 运行超时：说明系统会在 15 秒单次超时、45 秒总预算内重试一次；仍失败时自动回退确定性安全基线，主流程不中断。
- 如果 A2A 未触发：说明本次没有跨仓协商需求，保留记忆面板展示即可。
