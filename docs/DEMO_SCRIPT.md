# 5 分钟现场演示脚本

## 0:00–0:40 定位

> 急先锋不是灾害监测系统，而是事件确认后的应急资源调度推演平台。用户上传本单位物资和库存，系统生成多套方案并由独立智能体核验。

展示物资库、库存快照和车辆路线数量。

## 0:40–1:30 配置需求

选择“武汉暴雨洪涝应急演练”。展示：

- II 级事件
- 12000 人受影响
- 多条主通道封闭
- 6 类物资需求

说明物资是从物资库中选择，不是自由文本输入。

## 1:30–2:30 启动智能体

点击“启动多智能体推演”。观察右侧实时事件：

1. 数据快照冻结
2. 需求研判完成
3. 三套候选方案生成
4. 独立核验退回
5. 匹配智能体重新规划
6. 第二轮核验通过
7. 交付包生成

强调硬规则由代码计算，模型负责理解和解释。

## 2:30–3:40 多方案对比

切换方案，展示：

- 预估成本
- 最长时效
- 需求覆盖率
- 车辆趟次
- 独立核验评分
- 仓库到安置点的地图路线

说明第一轮为何被退回、第二轮改了什么。

## 3:40–4:20 交付与审批

打开“交付包”，展示风险提示、执行前检查、时间线和数据依据。点击人工审批通过，导出报告。

## 4:20–5:00 边界

> 本系统不宣称自动发现灾害或自动指挥救援。它用于预案编制、应急演练和辅助决策。生产落地需要授权接入真实库存、路网、运力和指挥系统。
