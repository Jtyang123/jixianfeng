# 安装与运行说明

## Windows 本地运行

1. 解压 `赛题一+OKC+急先锋_可运行演示包.zip`。
2. 安装 Python 3.10+、Node.js 18+ 和 npm。
3. 在项目根目录运行 `setup.cmd`。
4. 运行 `start.cmd`。
5. 浏览器访问 `http://127.0.0.1:8010`。

首次打开会进入登录页。初始管理员账号为 `admin`，密码有两种来源：

- **默认**：`.env` 中的 `AUTH_BOOTSTRAP_PASSWORD` 留空，系统首次启动时随机生成 18 字节口令，写入项目根目录 `data/bootstrap-admin-password.txt`，打开该文件复制密码即可登录。
- **已指定**：若部署者在 `.env` 中填了 `AUTH_BOOTSTRAP_PASSWORD`，则使用该值登录。

首次登录后请点击右上角钥匙按钮修改密码，并删除 `data/bootstrap-admin-password.txt`。仓库与提交包中均不包含明文密码。

未配置 PostgreSQL 时自动回退 SQLite；未配置 LLM 或 AgentArts 时自动使用本地确定性流程。

## Docker

```powershell
docker compose up --build -d
```

默认访问 `http://127.0.0.1:8010`。

## 演示前检查

```powershell
cd backend
..\.venv\Scripts\python.exe -m benchmark.demo_preflight
```

确认 `blockers=[]`、`latest_run.status=awaiting_approval`、`latest_run.verdict=pass`。
