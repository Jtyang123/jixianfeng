# 安装与运行说明

## Windows 本地运行

1. 解压 `赛题一+OKC+急先锋_可运行演示包.zip`。
2. 安装 Python 3.10+、Node.js 18+ 和 npm。
3. 在项目根目录运行 `setup.cmd`。
4. 运行 `start.cmd`。
5. 浏览器访问 `http://127.0.0.1:8010`。

首次打开会进入登录页。**初始管理员账号固定为 `admin`**，密码有两种来源：

1. **看启动窗口（最快）**：`start.cmd` 的窗口会打印一段标题为「急先锋 · 首次启动，已创建管理员账号」的信息，里面直接给了 `用户名 / 密码 / 登录地址`，照抄即可。
2. **读凭据文件**：打开项目根目录 `data/bootstrap-admin-password.txt`，文件内容就是密码。

为什么不能直接写在文档里：密码在首次启动时由系统随机生成（18 字节），只存在于本机，仓库与提交包中都不含明文密码，所以任何文档都不可能给出一个固定值。

若部署者已在 `.env` 中设置 `AUTH_BOOTSTRAP_PASSWORD`，系统会直接使用该值建号，启动窗口会提示「使用 .env 中 AUTH_BOOTSTRAP_PASSWORD 配置的值」，此时用该值登录。

首次登录后请点击右上角钥匙按钮修改密码，并删除 `data/bootstrap-admin-password.txt`。若已经改过密码又忘记了，删除 `data/` 下的数据库文件重新启动，系统会按上述流程重新生成管理员账号。

未配置 PostgreSQL 时自动回退 SQLite；未配置 LLM 或 AgentArts 时自动使用本地确定性流程。

## Docker

```powershell
docker compose up --build -d
```

默认访问 `http://127.0.0.1:8010`。

## 演示前检查

```powershell
cd backend
..\.venv\Scripts\python.exe -m benchmark.demo_preflight
```

确认 `blockers` 为空数组、`recent_runs.needs_human_ratio=0.0`、`agentarts.online_rate=1.0`，且 `recommended_demo_mode` 为 `llm-planner`。2026-11-15 实测：四端点 4/4 在线（均值约 2.5 秒）、近期 20 次运行 0 次转人工、推荐运行时 `llm-planner`。
