# OKC 队伍相关证明材料清单

本目录只能放入 OKC 参赛队伍自有的真实材料。严禁使用非参赛队伍材料，严禁伪造资质、应用证明或合作证明。

## 必备材料

- [ ] 队伍成员学生证、学生身份证明或在读证明
- [ ] 队伍所在学校 / 单位信息
- [ ] 指导教师信息与证明材料（如赛制要求）
- [ ] 核心成员名单、角色分工与个人履历
- [ ] 项目原创性声明或代码归属说明

## 可选加分材料

- [ ] 软件著作权、专利或受理通知书
- [ ] 竞赛获奖、项目立项、创新项目证明
- [ ] 真实单位试用、应用推广或合作证明
- [ ] 项目演示链接、部署证明或验收记录
- [ ] 其他能够证明团队能力和项目真实性的材料

## 文件命名建议

```text
OKC_成员姓名_学生身份证明.pdf
OKC_指导教师证明.pdf
OKC_软件著作权证书.pdf
OKC_应用试用证明.pdf
```

提交前逐项确认材料真实、清晰、可读，并在最终提交包中保留本清单。
